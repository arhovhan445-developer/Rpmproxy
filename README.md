# RPM Proxy

Прокси ELM327 для Rev Heads: RPM считается от положения педали газа (PID 0149).

1. Загрузите проект в репозиторий GitHub.
2. Вкладка Actions -> Build APK -> дождитесь зелёной галочки.
3. Скачайте артефакт RpmProxy-debug-apk, распакуйте, установите app-debug.apk.
4. В приложении выберите ELM327, нажмите Старт.
5. В Rev Heads: WiFi, IP 127.0.0.1, порт 35000.
